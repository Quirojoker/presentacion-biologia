🧬 La Dieta del Picor: El Método Científico en la Alergia Alimentaria Canina

¡Bienvenidos al repositorio de esta presentación interactiva! Este proyecto fue desarrollado utilizando HTML, CSS y JavaScript con el propósito de explicar de forma dinámica, visual y práctica cómo se aplica el método científico a un caso real de la biología y la medicina veterinaria: la resolución de una alergia alimentaria en perros.

🚀 Características del Proyecto

Interactividad Total: Diseñado como una presentación web fluida para navegar paso a paso por las fases de la investigación.

Enfoque Práctico: Traduce conceptos abstractos del método científico en un escenario cotidiano (la búsqueda de la causa de la picazón en un canino).

Diseño Adaptable (Responsive): Estilizado con CSS moderno para garantizar una lectura clara en diferentes tamaños de pantalla.

Sin Dependencias Externas: Construido con tecnologías web nativas para asegurar una carga rápida y un rendimiento óptimo.

🔬 Pasos del Método Científico Abordados

Observación: El perro presenta picor constante e irritación en la piel.

Planteamiento del Problema: ¿Se debe a una alergia a un componente específico de su dieta?

Hipótesis: Si eliminamos ciertos ingredientes alérgenos comunes mediante una dieta de exclusión, los síntomas cutáneos disminuirán.

Experimentación: Aplicación controlada de la "dieta del picor" y registro de los cambios.

Análisis de Resultados: Evaluación de la mejoría tras la retirada de los alérgenos sospechosos.

Conclusión: Validación o refutación de la hipótesis inicial sobre el alérgeno alimentario.

🛠️ Tecnologías Utilizadas

HTML5: Estructura semántica de las diapositivas y contenidos.

CSS3: Estilos visuales, tipografías, colores y diseño responsivo.

JavaScript: Lógica de navegación interactiva entre las diferentes fases del método científico.
